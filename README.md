# 🏛️ Egyptian Labor Law Expert System

An **Expert System** built using **Python** and **Tkinter** that provides preliminary legal consultations based on the **Egyptian Labor Law**. The system allows users to select a legal topic, enter relevant information, and instantly receive an advisory legal response.

---

## ✨ Features

* Modern GUI with a Green Neon theme
* Preliminary legal consultations in multiple topics:

  * 📅 Annual Leave
  * ⏰ Working Hours & Overtime
  * 💰 End of Service & Gratuity
  * 📄 Employment Contract Termination
* Displays relevant labor law articles for each topic
* Automatic calculations (e.g. end-of-service compensation)
* Save consultations as JSON files
* Consultation history log

---

## 🧠 Project Concept

This project simulates an **Expert System** through:

* A **Knowledge Base** containing Egyptian Labor Law articles
* A set of **Rule-Based Inference Logic**
* An interactive graphical user interface for user interaction

⚠️ **Disclaimer:** The provided results are for educational and guidance purposes only and do not replace professional legal advice.
